# HM Logging Console Provider

`HDev.Hm.Logging.Providers.Console` is the planned Console destination adapter for `HDev.Hm.Logging.Core`.

This package is in its Foundation phase. Its project, package metadata, dependency boundary, Quality gates, and Delivery safeguards exist, but no Console provider, registration method, formatting, routing, color, or options behavior has been implemented. The package is therefore not published and must not yet be installed or used.

Installation, `AddLoggingConsole(...)` registration, configuration defaults, examples, output behavior, and operational guidance will be documented when the functional Console implementation is complete.
